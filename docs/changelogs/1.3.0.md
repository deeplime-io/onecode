## :warning: Breaking changes

Python 3.10 and older are no longer supported. OneCode now requires Python 3.11, 3.12, 3.13, or 3.14.

The `check_type` decorator and the `ONECODE_DO_TYPECHECK` environment variable are removed. `Env.ONECODE_DO_TYPECHECK` is no longer available, and Pydantic is no longer a developer dependency.
